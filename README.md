# Slide — piece util

CAD of **useful pieces** used on the Slide robot: motors, wheels, pumps, pneumatic fittings, servos, pulleys, rails, batteries and more. It will probably save you a lot of time.

This repo is the `piece util` folder of the [slide](https://github.com/Eurobot-2026-CAD-departement/slide) repository, published on its own for convenience (content is intentionally duplicated).

Most folders are `.snapshot` downloads from vendor/CAD libraries (STEP/SolidWorks files and datasheets), alongside team-made parts such as `base euro`, crate models and servo-arm heads.

---

Part of the CAD work of the **Aerobotix (INSAT, Tunisia) Eurobot 2026 team** — see the [organization](https://github.com/Eurobot-2026-CAD-departement) for the other repositories.
